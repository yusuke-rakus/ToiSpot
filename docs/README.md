## 文書の扱い

店舗表示の起動・データ投入・取得上限・確認方法は[サンプルデータ](development/sample-data.md)を参照する。

ローカル管理者の環境変数・ログイン・登録編集・管理者変更は[管理者機能](development/admin.md)を参照する。本番のGoogleアカウント事前登録、Actions Secrets、デプロイは[Firebaseへのデプロイ手順](operations/deployment.md)を参照する。

この文書を、実装時に参照・更新する仕様のたたき台とする。現時点では、すべての記載が採用済みの仕様ではない。

| 区分     | 意味                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 確定     | ユーザーの依頼・回答で確認済みの要件                                                 |
| 採用     | ユーザーから判断を委任された範囲で選定した技術。パッケージ導入済みという意味ではない |
| 提案     | 現時点の推奨案。詳細検討で変更できる                                                 |
| 未決     | 実装前または該当機能の着手前に決定が必要な事項                                       |
| 調査結果 | 公式資料で確認した情報。料金・制限は公開前に再確認する                               |

未決事項を実装者の判断だけで確定仕様に置き換えない。決定後は、該当箇所と[決定履歴](decisions/README.md)を更新する。画面・データ・権限に関係する変更は、関連する仕様と検証項目にも反映する。
