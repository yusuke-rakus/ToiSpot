# 実装ロードマップ

[概要](../../README.md) · [文書一覧](../README.md)

以下は今後の作業順序案。この文書の作成依頼だけで、クラウド設定やアプリ公開を実施したものとは扱わない。

1. 未決事項を整理し、初期版の画面フローとデータ定義を確定する。
2. React・TypeScript・Vite、shadcn/ui・Tailwind CSS、TanStack Query・Routerの土台を用意し、採用済みライブラリを用いて型・モックデータ・フォーム・検証環境を整える。
3. Firebase Emulator上で認証・Security Rules・保存処理を実装、検証する。
4. 公開地図・一覧・詳細・絞り込みと、管理者の登録・編集機能を実装する。
5. 新規Firebaseプロジェクトを作成し、請求先、DB、認証、Maps、キー制限、通知を設定する。
6. 本番サービスとの接続とスマホでの動作を確認する。
7. 公開ページ、料金の再確認、運用手順、復旧手順を整え、Hostingへ公開する。

リポジトリには実装とともに、環境変数の記入例、ローカル起動方法、検証方法、Firebaseの設定・公開手順を残す。パスワードやサービスアカウント秘密鍵は含めない。

## 現在地（2026-11-05）

- ドキュメント分割と推奨技術の依存関係導入、起動・検証の基盤を整備。
- Queryの取得設定、Routerの入口、shadcn/ui・Tailwindの基本設定を実装。
- Firebaseクライアントの遅延初期化とローカルEmulator設定を用意。
- APIキーからの地図表示、現在地への移動、コンビニのピン選択を実装。任意地点のピン設置・座標表示・コピーは削除。地図だけの確認にはFirebase接続が不要。
- Firestoreの共有Zodスキーマ、Query経由の取得と地図・一覧・詳細表示を実装。登録はPlacesからの店舗に限定。ローカルでは現在の万願寺周辺のテスト店舗7件をシードで再現できる。[実行方法と範囲](sample-data.md)を参照。
- `stores`は公開読み取り、許可UIDの管理者だけに作成・更新を許可。取得はEmulatorと設定済みクラウドで有効で、最大100件・省略と不正データの案内・手動更新に対応。
- メール・パスワードログイン、環境変数からのAuthユーザー・管理者UID設定、同じ`/`からの登録編集フォーム・保存・再取得を実装。[管理者機能](admin.md)を参照。
- 現在地から半径3kmの周辺検索を実装済み。クラウド接続・設定検査付き本番ビルド・Actionsを実装済み。店舗削除は許可しない。クラウド設定と本番公開・本番のメール・パスワード認証の検証は未実施。
- 次は[Q-01〜Q-05](../decisions/README.md)の残る運用・入力仕様を詰める。サンプル表示の実装だけで検索・管理者機能の仕様が確定したとは扱わない。
